56屆技能競賽決賽第三天

這裡是剛拿完獎牌在自滿的Niugnep。 第三天從兩點開始，主要是頒獎跟閉幕典禮。 進入會場 這次的會場在二館7樓，還好沒人來找我吼。 進入前還要做安檢，然後我打開了包包，他們只能對著滿包的垃圾安檢，不知道有沒有笑場。 我一開始還找不到座位咧>w< 會場佈置 冷死了。 我居然忘了帶外套！（所以我的雞皮疙瘩持續了三個鐘頭） 場地很大，然後還有個大螢幕，依舊是那個「挑戰！ㄐㄅ魂」。 沒有意義的項目 然後勞動部長講了一堆幹話，講完以後輪到贊助商。 贊助商多到我都數不完，難怪配備這麼好。 結束之後還有表演咧… 銅牌！！！ 好啦，結果就是我拿了「商務軟體設計青少年組」的銅牌。 其實還挺爽的，因為金銀牌都是九年級，算是比下有餘了（？）。 而且昨天翻那麼多車居然還能銅牌吼… 再度e04話 主持人為了等總統帶了一堆活動，辛苦了。 然後，誰能告訴我為什麼總統的e04話可以這麼多啊… 他露個頭就好下去了，硬生生講了十分鐘毫無重點的e04話啊！ 而且我打算明年參加網頁，所以可能得再聽一次… 抽獎是吧？ 好，我沒抽到。 今天懶的寫，就醬吧

56屆技能競賽決賽第二天

啊，這裡是剛比完賽的Niugnep。 今天圖片不會多，因為懶owo 比賽前 早餐是麥當勞。 我選的是豬肉滿福堡+咖啡，其實挺好吃的，但是我咖啡在捷運上撒了，還好沒什麼事。 比賽項目1 比賽項目1就是實作程式，這次的題目是微信滬想生活。 說白了就是個聊天軟體，參加了青年組商軟設計應該會有印象。 這次給的資料庫與以往不一樣，給的是.sql檔案，也就是SQL查詢語言的腳本檔案，要用這檔案建立資料庫。令我不解的是，一堆人不知道這幹嘛的。 然後就是Entity Framework了。它是一個讓SQL查詢沒那麼反人類的.NET工具。比如SQL指令長這樣： SELECT * FROM users WHERE type = 'homo'; 然後Entity Framework長這樣： using (var db = new Entities()){ var homos = db.users.Where(x => x.type == homo); } 看起來舒服了吧！ 但是我的EF卻一直炸一直炸，後來才發現居然是引用了System.Data，要引用System.Data.Entity.Core才能繼續用… 我是很不清楚我的分數如何，因為好像只有我把這堆SQL修好，但程式部份我又沒做完… 比賽項目2、3 然後就是簡報了。 簡報部份要用到PowerPoint跟Visio，整個比賽就是微軟全家桶。 這個簡報其實我沒有太多素材，因為沒做完。雖然可從範例截圖，但我當時沒想到。 報告的部份每個人各有風格，其中有幾位我比較有印象的： 一個用英文講的同學 一個只有簡報不報告的同學 好幾個全中文的同學（簡報要求英文；報告語言不拘） 還有個直接攤牌「我沒做簡報」的 最後一個就看我旁邊那位在憋笑。 明天再見！ 沒啦！今天的篇幅比昨天少不少，因為我沒梗了。 明天頒獎好緊張啊～

56屆技能競賽決賽第一天

好的，這裡是還沒開始繼續練的Niugnep。 在這個第56屆技能競賽當中，我從北區成功晉級到了全國決賽，與中、南部的同學一起比賽。 對於技能競賽是什麼，我不想多談，有需要可以去看他們的技能競賽主題網。 國中能參賽嗎？ 可以喔！我參加的是J09的職類，也就是「青少年組商務軟體設計」——說是商務軟體設計，其實也沒多商務。 這次的比賽地點是在南港展覽館一館的四樓，要來的話不要刻意來找我，我會覺得很煩。 總之，大概是這樣，以下就是我今天的行程啦。 （你再說一次，挑戰什麼！？） 早上 我們培訓的學校位在捷運海山站，可以直接乘坐板南線通到南港展覽館。 到場後要先去報到、領狗牌跟新手教學。 （你確定這圖片不是AI？） 好玩的是這狗牌的掛繩還是條C to C的傳輸線呢。 領完這倆之後我們就上樓了。 因為比賽場地在四樓，我們今天的行動也全都集中在四樓。 不過我想吐嘈的是，這地方長的也太像IKEA的倉庫了吧！ 都是那種天花板支架不藏起來，然後灰白色的感覺。 中午 其實剛領完就吃飯了。 中午吃的是他們發的便當，其實不難吃。 雖說是由蓮藕、地瓜、青菜、雞腿、紫米飯組成的「養生全餐」，但是可能我家口味本就比較淡，我覺得挺好吃的。 嘛，一堆同學在靠腰就是了。 還有一根香蕉，應該是飯後水果，或是純粹呼應標語的。 此外就是大螢幕輪播選手製作的個人介紹簡報，好像只有我的用的是幾乎純英文？ 下午 今天青少年組沒有要比賽。 我們要做的就是聽幹話規則，然後測試場地。 話說這裡的電腦桌布是技能競賽吉祥物，長得超ㄎㄧㄤ，因為我想拍的時候好像禁止拍照，所以我沒圖片。 但是我有那隻吉祥物的徽章。 此外還有一個新手大禮包，裡面有： 戰袍（T-shirt） 飲料提袋 購物袋 原子筆 素描本 便條紙 徽章 晚上 我們入住的又是高級飯店，叫什麼我就不多說了。 （為什麼要說又呢） 我是不太明白學校哪來那麼多錢去定這些超高級飯店的，大概是政府出錢吧！ 晚餐有整整250元可以報銷（一定還是政府），所以我就吃的不錯。 麥當勞只花了一百多（我平時都剛好一百）；手搖飲55；泡麵23。 麥當勞變成數學題了 明天再加油吧！ 今天先到這樣，第一天還是沒什麼好寫的。
