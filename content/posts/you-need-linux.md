是的！你需要Linux！  
這樣我說話的口吻像是Wiwi官大為似的（[舉例](https://wiwi.blog/blog/you-should-use-rss)），但是這真的很重要。  

## Linux是什麼？
一個由Linus Torvalds撰寫的系統核心，最大特點就是開源。因為這一點，你可以在各種電腦上安裝。小至幾十台幣的控制器，大至世界前五百大超級電腦，都是用Linux。  
你可能覺得這跟你無關，但是實際上，Windows正在變得越來越爛，比如自動更新、監視等。  
舉個例子。假如我今天製作一個茶壺，很多人用，但是後來的產品加上了廣告和監視器，怎麼辦？  
好說嘛，換一個牌子唄。  
為什麼同樣的道理你不換掉Windows呢？作業系統跟茶壺一樣都是工具，為什麼你可以忍受作業系統變爛，不能忍受茶壺變爛呢？你一天泡茶的時間應該比用電腦的時間少吧？  
而且macOS**也有**同樣的問題，不要以為用Mac就沒差。

## Linux好多！
Linux只是個核心，但是作業系統本體有很多，它們叫做發行版，各自代表不同的理念。  
光是我舉得出的例子就有：
 * Linux Mint
 * Debian Linux
 * Arch Linux
 * Fedora Linux
 * Pop!_OS
 * Red Hat Enterprise Linux（企業用的）
 * Ubuntu
 * SteamOS
 * 以及千百種發行版
 
那麼你該選哪個系統呢？  
對於新手而言，最穩定的肯定是Linux Mint。  
它不花錢、有大量教學跟論壇、簡單易用，而且長的像Windows，轉移難度低。

如果你是馬上上戰場的新手大學生，我強烈建議在虛擬機裝個Fedora。  
企業很多都是用RHEL，它的組件管理工具（`dnf install <東西>`）跟Fedora相通，可以盡早練習。
